# Loader Boundary

## 基本原則

- Forge 固有の登録、event bus、設定、client 初期化は、共通ロジックとは別物として扱う。
- 1.20.1 で必要な接着コードが、1.21.1 NeoForge でも同じ形で成立すると決めつけない。
- 迷ったら「共通ロジックだけを運び、接着コードは port 先で書き直す」を優先する。

## 分離の目安

- registry 登録 API
- event bus 購読
- `mods.toml` と依存定義
- datagen 入口と run 設定
- client 専用参照の隔離

## コメント方針

- なぜ Forge 側でこの接着コードが必要かを短く書く。
- 1.21.1 側でそのまま使えない可能性が高い場合は、その理由を短く書く。
- 将来の port 作業者が「ここは共通ロジックではない」と即判断できる粒度で残す。
